HTML, que significa HyperText Markup Language (Lenguaje de Marcado de Hipertexto), es el lenguaje fundamental utilizado para crear y estructurar páginas web. Aunque muchas personas lo llaman un lenguaje de programación, técnicamente HTML es un lenguaje de marcado, porque se utiliza principalmente para organizar y describir el contenido que aparecerá en una página web. ¿Qué es HTML? HTML permite definir la estructura de una página mediante elementos llamados etiquetas o tags. Estas etiquetas indican al navegador qué tipo de contenido se está mostrando. Por ejemplo, se pueden utilizar etiquetas para crear títulos, párrafos, imágenes, enlaces, listas, tablas, formularios, botones y muchas otras partes de una página web. Cuando una persona entra a una página web, el navegador como Google Chrome, Microsoft Edge o Mozilla Firefox interpreta el código HTML y lo convierte en una representación visual que el usuario puede observar e interactuar. Básicamente, el navegador recibe un montón de texto con símbolos y decide cómo convertirlo en una página decente.
